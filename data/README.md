# Private competition inputs

Place the authorized files here locally:

| File | Columns | Rows |
|---|---|---:|
| `train.csv` | `id,subject,body,label` | 500 |
| `test.csv` | `id,subject,body` | 100 |
| `sample_submission.csv` | `Id,label` | 100 |

Label 0 means non-phishing and label 1 means phishing. IDs match rows; they are not predictive inputs. Sample labels are placeholders. Obtain the original files through the course competition under its access rules; they are not redistributed in this repository.
